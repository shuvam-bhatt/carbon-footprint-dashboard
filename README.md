The Carbon Footprint Dashboard is an innovative tool designed to address the critical challenge of managing carbon emissions in coal mines. With the growing focus on sustainability, this platform empowers industries and policymakers to monitor and mitigate their carbon footprint effectively.

The application evaluates carbon emissions based on activity-specific data and estimates the efficiency of existing carbon sinks. It highlights gaps between emissions and absorption capacities, enabling users to make data-driven decisions to achieve carbon neutrality.

Built with modern web technologies, the dashboard is user-friendly, scalable, and optimized for performance. Its intuitive interface simplifies data visualization, making it accessible to both technical and non-technical users.

Environmental analysts, mining companies, and regulatory bodies can leverage this tool to track emissions, analyze trends, and implement sustainable strategies. The platform supports better planning and reporting, aligning with global carbon reduction initiatives.

## ✨ Features

- 📊 Quantifies carbon emissions activity-wise.
- 🌳 Estimates existing carbon sinks.
- 📉 Performs gap analysis between emissions and sinks.
- ♻️ Suggests pathways to achieve carbon neutrality.
- 📈 Provides visualizations like bar charts and line graphs.

## 🚀 Setup Instructions

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd carbon-footprint-dashboard
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   cd backend
   node server.js
   ```
   ```bash
   cd ..
   cd frontend
   npm start
   ```
5. Access the application in your browser at:
   ```
   http://localhost:3000
   ```
